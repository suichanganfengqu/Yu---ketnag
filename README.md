# Yu---ketnag
一个油猴脚本，用于刷雨课堂的ppt阅读任务

------------------------------------------
以下是使用教程（推荐使用Edge浏览器）：


1.先去插件市场下载“篡改猴”插件

2.打开篡改猴点击“添加新的脚本”

3.从“文件”中选中“打开”选择下载好的文件“chnagjiangyvketangX.x.x”

4.选择覆盖并保存

5.在编辑器旁边找到设置下拉找到“为用户匹配”

将https://changjiang.yuketang.cn/*粘贴进去

这样就完成配置了

------------------------------------------------------------

然后在插件页面中把你导入的脚本打开然后进入雨课堂ppt页面他就会自动刷

--------------------------------------------------------------
功能介绍：

0.1.1版本：

【自动跳转未完成学习的ppt并自动阅读】

【附带操作台可实现手动停止，暂停和开始】

【在识别到网页链接中有video等视频链接自动跳过】

【如果有雨课堂本身的bug，出现某一张幻灯片的“未读”标识未消失时自动计时5s后跳过本张幻灯片】

【可重复检查是否有未读的幻灯片并自动打开阅读】
